Put CSL aircraft model packages in this folder, one folder per package.

A good free set is the Bluebell OBJ8 CSL packages (search "Bluebell CSL" on forums.x-plane.org).
If you already use LiveTraffic or xPilot, you can copy their CSL folders here instead.

Restart X-Plane after adding models. Airwave picks a model for each aircraft by its ICAO type
(A20N, B738, AT76...) and airline (AEE, RYR, OAL...). The Airwave Pilot window shows which model was chosen.
